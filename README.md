# Tracey's Art Therapy Website

A redesigned website for Tracey E. Saia, Art Therapy. The site is built as a Vite + React single-page app and deployed through Codex/Sites to Cloudflare-backed hosting.

Live site:

- https://traceyesaia.com
- https://www.traceyesaia.com
- https://traceys-art-therapy.franksaia.chatgpt.site

## What Is Included

- Homepage with ocean hero imagery
- Therapy/services pages
- What to expect page
- Art therapy overview
- About Tracey page with affiliations, podcasts, coloring book, newsletter, and social links
- Rewired 10-week course overview
- Corporate workshops page
- Contact page

## Tech Stack

- React
- TypeScript
- Vite
- Motion for React
- Lucide icons

## Local Development

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Deployment

The project is connected to Codex/Sites through `.openai/hosting.json`.

The Git remote named `sites` is used for Sites deployment. The GitHub remote named `origin` points to this repository.
